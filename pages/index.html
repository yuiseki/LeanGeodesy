LeanGeodesy

The mathematics GIS software takes for granted, proved in Lean 4: the shape of the Earth, map projections and their distortion, shortest routes, web map tiles and coordinate reference systems.

The book (English)

Read the library in order, in three parts: the Earth as an ellipsoid, tiles, and coordinate reference systems. Every declaration is shown from the built library.
